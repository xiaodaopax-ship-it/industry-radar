    台账估值台账 · 本期变化

    每周更新后按默认参数给每家公司记一笔（股价、Bear / Base / Bull、隐含增速、FCF 利润率与口径、起始增速、一致预期），只追加不改写，用来看“这一期数据变了什么、估值因此变了多少”。基准估值的变化按 营收基数 R0 → FCF 利润率路径（m0 / 口径 / 爬坡起点）→ 起始增速 g0 → 净现金与股数 → 参数（rf / ERP / gT / 爬坡 N、T）的固定顺序依次替换做归因，各项相加等于总变化；顺序不同拆分会不同。

    台账记录的是模型在默认参数下的输出，用来对比数据变化带来的估值变化；不是目标价，不是买卖建议；方法未回测。

    维度权重0 = 不计分，默认都是 1；修改后立即生效并保存在本浏览器
    评分规则分组、维度、百分位和总分怎么算
    • 分组：金融类口径（profile = financial）单独一组；标准口径中属于周期性环节的公司归“周期”组，不参与评分（周期环节：盈利高点时估值最低，不参与排序）；其余为标准组。百分位只在同一组内计算。
    • 标准口径维度：营收同比 ↑、增速变化（加速）↑、毛利率 ↑、毛利率变化 ↑、营业利润率 ↑、增速调整后市销率 ↓（只在 > 0 时计入）、稀释 ↓、财报超预期 ↑。
    • 金融口径维度：营收同比 ↑、税前利润率 ↑、税前利润率变化 ↑、ROE ↑、市净率 ↓（只在 > 0 时计入）、稀释 ↓。
    • 数据异常：营业利润率被标为异常时不计营业利润率；营收增速异常时不计营收同比和增速变化；税前利润异常时不计税前利润率及其变化。表中用 ⚠ 标出。
    • 百分位：组内在该维度有有效数值的公司按数值排序，并列取平均名次，映射到 0–100，最好 = 100、最差 = 0；只有一家有数值时记 50。权重为 0 的维度不计。
    • 总分 = Σ(权重 × 百分位) ÷ Σ权重，只算有数据的维度，保留 1 位小数。覆盖维度 x/y = 有数据的维度数 / 权重 > 0 的维度数；x 小于 y 的一半（向上取整）时标“数据不足”，排在本组其他公司之后。组内只有 1 家时不打分。
    • 不计分：股价高低、PEG、分析师目标价、评级、页面的“结论”。表格里的绿色底 = 本组该维度最好，红色底 = 最差。

    池内相对排序：只反映所选这几家在下列口径上的相对位置，换一批公司分数就会变。不是买卖建议，不预测股价；PEG 与分析师目标价只展示、不计分。

    本行业已排除的公司

    美国公司：营收、毛利、营业利润、净利润、股数、现金来自 SEC XBRL frames（金融类环节另取税前利润、股东权益、信用损失拨备和净利息收入；金融类龙头的这几项来自 Yahoo 财务时间序列）；行业代码、股票代码、Form 4 来自 SEC submissions。本看板只保留美国上市公司（config.json markets.us_only = true；台湾、日本、韩国、欧洲上市的公司不抓取也不显示，改回 false 可恢复）。在美上市的 ADR 若只交 20-F，部分财务来自 Yahoo 财务时间序列。股价、市值、EPS 实际与预期、一致预期、财报日、分析师人数来自 Yahoo Finance（非官方接口）。

    研究优先池：先剔除周期性环节、缺市值、稀释超过 50%、亏损且现金不足 6 个季度、营收同比超过 300% 的公司，再按 10 个因子在本行业候选中的百分位排名取平均。权重相同，没有经过回测，只用来排研究顺序。

    现金流估值（情景参考，不是目标价，不是买卖建议）：只展示，不进入评分、因子、结论、PEG 筛选分层和对比池评分。数据由 python -m radar valuation 取得（按公司缓存，可中断续跑），计算在页面里完成，参数在“估值参数”里改。

    数据：SEC 申报公司来自 companyfacts（us-gaap）：经营现金流 NetCashProvidedByUsedInOperatingActivities（缺时 …ContinuingOperations）、资本开支 PaymentsToAcquirePropertyPlantAndEquipment（缺时 PaymentsToAcquireProductiveAssets、PaymentsForCapitalImprovements），营收按营收标签顺序；最近 5 个财年（期间约 365 天、同一期间取最新申报的数字），TTM = 上一财年 + 今年累计 − 去年同期累计（10-Q 的年初至今口径）。现金 = CashAndCashEquivalentsAtCarryingValue（缺时含受限现金的口径）+ ShortTermInvestments / MarketableSecuritiesCurrent / AvailableForSaleSecuritiesDebtSecuritiesCurrent（取第一个有值的）；债务 = LongTermDebt（含一年内到期部分），缺时 LongTermDebtNoncurrent + LongTermDebtCurrent，再缺时 …AndCapitalLeaseObligations（含融资租赁）或可转债科目，另加 ShortTermBorrowings（没有时用 CommercialPaper）；不含经营租赁负债；都在现金科目最新的资产负债表日。股数：dei EntityCommonStockSharesOutstanding（缺时最近一季稀释加权股数），与“市值 ÷ 股价”相差超过 25%（多类股、ADR）时改用后者。只交 20-F / 40-F 的公司和海外公司用 Yahoo 财务时间序列（年度经营现金流、资本开支、营收、最近一季现金与短期投资、总债务减租赁负债，约 4 个财年，非官方接口），股数用市值 ÷ 股价；报表币种与股价币种不同时按页面汇率换算营收和净现金。一致预期营收：Yahoo earningsTrend revenueEstimate（本财年 0y、下一财年 +1y，含分析师人数）。无风险利率：美国财政部每日国债收益率曲线 CSV 的 10 年期（取不到时 FRED DGS10；都取不到时需要手动填写）。

    FCF 折现：FCF = 经营现金流 − 资本开支，FCF 利润率 = FCF ÷ 营收。基准利润率按参数“FCF 利润率口径”取（全局设定；每张评估卡可以“单独设定”只对这家公司生效的口径和爬坡参数，卡里标“本公司单独设定”）：近 3 年平均（不足时用现有年份并注明；周期性环节用最近 5 个财年，标“周期：用多年平均利润率”）；最近财年；TTM；利润率爬坡：第 t 年利润率 m_t = m_start + (T − m_start) × min(t ÷ N, 1)，第 N 年（默认 5）到达稳态 T（默认 15%）后不变，终值用第 10 年的利润率；起点 m_start = TTM 利润率（TTM 可用时），否则最近财年；N 和 T 是用户假设，不是数据得出。一次性收入粗筛（有 TTM 时）：TTM 营收超过最近财年 1.5 倍；或一致预期下一财年营收比本财年低 30% 以上；或一致预期 EPS 下一财年不到本财年的 70%（两期都 > 0）；后两条要求两期都至少 3 家分析师。任一条命中，TTM 不用于自动口径和爬坡起点，卡里写“疑似一次性收入，未外推：…”；手动选 TTM 时照用，但同样提示。自动（默认），按顺序：周期性环节 → 多年平均（不用 TTM 和爬坡，可能是周期高点的现金流）；TTM 可用、高于近 3 年平均、且最近三个财年利润率逐年上升（FY−2 < FY−1 < FY0）→ TTM；近 3 年平均 ≤ 0 且最近财年利润率高于上一财年 → 爬坡；否则 → 近 3 年平均。所选口径缺数据时回退到平均并注明。卡里写明用了哪个口径和原因，同时列出平均和 TTM 两个数，两者相差超过 10pt 时提示注意一次性因素（预收、回款、资本开支推迟）；爬坡时列出逐年利润率路径。FCF ≤ 0 的判断（平均 / 最近财年 / TTM：m0 ≤ 0；爬坡：稳态 T ≤ 0）、三种情景、反向 DCF、敏感性、价格轴、PEG 筛选列和对比池列都用同一条利润率路径。基准起始增速 g0：一致预期营收增速（FY+1 ÷ FY0 − 1；没有 FY+1 时 FY0 ÷ 上一财年 − 1），要求至少 3 家分析师；否则过去 3 年营收 CAGR；再否则 TTM 营收同比；截断在 −10% ~ 上限（默认 40%，显示“已截断”）。起点营收 R0 = TTM 营收。10 年：第 t 年增速 g_t = g0 + (gT − g0) × (t − 1) ÷ 9，R_t = R_{t−1} × (1 + g_t)，FCF_t = R_t × m_t（非爬坡口径 m_t = m0 不变）；终值 TV = FCF_10 × (1 + gT) ÷ (r − gT)；EV = Σ FCF_t ÷ (1 + r)^t + TV ÷ (1 + r)^10；股权价值 = EV + 净现金（现金 − 债务）；每股价值 = 股权价值 ÷ 股数。

    情景：基准 r = rf + ERP（默认 5.0%，用户设定）；Bull r − 1pt、Bear r + 1pt；Bull g0 + |g0| × 30%、Bear g0 − |g0| × 30%；Bull m0 × 1.2、Bear m0 × 0.8（爬坡口径是稳态 T × 1.2 / × 0.8，起点和年数不变；幅度都可调）。gT 默认 2.5%（用户设定 2%–3%），不超过 rf，并且必须比各情景折现率低 0.5pt 以上，超出时自动压低并提示。反向 DCF：用基准 r、gT、m0，二分法在 −30% ~ 100% 内求使每股价值等于现价的 g0（“现价隐含前 10 年起始增速”），区间内无解时说明；另求基准增速下现价隐含的 FCF 利润率。爬坡口径下求 g0 时利润率路径固定；隐含利润率求的是“需要的稳态 FCF 利润率”T（起点和年数不变，FCF 对 T 是线性的）；利润率前几年为负时估值对 g0 不一定单调，二分法给出的是区间内的一个解。基准 FCF 利润率 ≤ 0（爬坡：稳态 T ≤ 0）时不做三种情景，只给“需要的 FCF 利润率”。敏感性：基准情景下 r ± 1 / 2pt × gT ± 0.5 / 1pt，r − gT ≤ 0.5pt 的格子不算。

    估值台账：python -m radar ledger 用 radar/valuation.py 的 dcf_entry（本页估值引擎的 Python 镜像，含 FCF 利润率口径和一次性收入规则；固定用默认参数，rf 取估值文件里的 10 年期国债收益率）给每家公司（按代码去重，取页面里的第一条评估口径）追加一条记录到本地 data/ledger/us_ledger.jsonl，只追加不改写；同一份估值文件 + 行情快照重复运行不会重复记录。“本期 vs 上期”：股价、基准估值、相对现价、隐含增速、一致预期增速与家数、目标价中位数的变化；基准估值变化按 ① 营收基数 R0 → ② FCF 利润率路径（m0 / 口径切换 / 爬坡起点）→ ③ 起始增速 g0 → ④ 净现金与股数 → ⑤ 参数 rf / ERP / gT / 爬坡 N、T 的顺序依次替换，每步的估值差就是该项贡献，各项相加等于总变化（交互影响计入靠后的一项，顺序不同拆分会不同）。结论句只陈述数字：最大的驱动项（第二项超过总变化 1/3 时也列出）、股价与估值是否同向；“基本面驱动”= 估值变化大于股价变化且营收 / 利润率 / 增速贡献过半，“价格驱动”= 股价变化 ≥ 2% 而估值变化 < 2%，“参数驱动”= 利率参数贡献过半。台账只展示，不进评分；不是目标价，不是买卖建议；方法未回测。

    金融口径（券商、交易所、放贷、保险、银行、抵押贷款 REIT 等，profile = financial）：不做 FCF 折现，用剩余收益法：合理市净率 = (ROE − gT) ÷ (r − gT)，每股价值 = 合理市净率 × 每股净资产（股东权益 ÷ 股数），ROE 为评估卡的 TTM ROE；情景 ROE ± |ROE| × 20%、r ∓ 1pt；反向：现价市净率对应的 ROE = gT + P/B × (r − gT)。不适用：权益 REIT（需 FFO/AFFO，暂不估值）、缺股价 / 股数 / 营收 / 现金流数据的公司，原因写在卡里。

    局限：DCF 对折现率和永续增速非常敏感；FCF 利润率用历史平均、最近财年或 TTM 外推十年（TTM 可能含预收、回款、资本开支推迟等一次性因素），爬坡口径的稳态利润率和年数是用户假设；一次性收入识别是规则粗筛，会漏判也会误判；商业模式、资本开支周期或股权激励（SBC 没有扣除）变化时误差大；一年的一致预期增速被当作 10 年衰减路径的起点；净现金不含经营租赁、养老金和少数股东权益；海外数据来自非官方接口；没有回测。

    金融类口径（券商、交易平台、交易所、放贷与先买后付，环节配置 profile = financial）：营收按 RevenuesNetOfInterestExpense → Revenues → 合同收入的顺序取（券商和放贷公司的合同收入通常只含手续费）；不看毛利率和现金跑道（现金大多是客户资金），清单改为增长、税前利润率、ROE（TTM 净利润 / 平均股东权益）、估值（市盈率、市净率、PEG）、资本（股东权益同比）、信用成本（放贷环节：信用损失拨备占收入及变化）、稀释、内部人、财报 vs 预期、关注度。门槛：周期性环节不剔除只提示；TTM 净亏损、股东权益为负、缺市值、稀释超过 50%、营收同比超过 300% 的不进入排序。排序因子：增速、加速、税前利润率、税前利润率趋势、ROE、PEG（没有可靠的 PEG 时用市净率）、股东权益增长、稀释、内部人、关注度、EPS 超预期，百分位只在同一口径的公司里计算。拨备超过收入的视为标签错误不使用；按公允价值计量贷款的公司（如 UPST）没有拨备科目。

    "占比"是在本工具覆盖公司中的市值占比，不是市场份额。龙头是手动挑选的，见 config/sectors.json。

    一句话介绍：优先用 notes.json 里的人工描述，其次是 profiles_zh.json 中按公司公开业务描述整理的中文概述，都没有时显示 Yahoo 的英文业务描述首句。

    已知局限：分类依赖 SIC 和 Yahoo 行业，比较粗；同一公司可能出现在两个行业；XBRL 和 Yahoo 偶有数据错误，异常值以原始财报为准；海外公司没有内部人交易数据。
